# 📅 Week 2: [Bash Git Ruff]

## 🛠️ 1. What I Built
- **Summary**:
This week, I created a Bash script (`prep_data.sh`) to automate the preparation of a dataset for my project. The script downloads the Iris dataset, adds a synthetic row, and generates a small report with the number of rows. I also created a Makefile to run the script easily and clean up the generated files.

- **Key Tools Used**: 
Bash, Makefile, Git, VsCode, macOS terminal

- **Artifact Location**:
scripts/prep_data.sh, Makefile, Dataset: `data/iris.csv` (generated by the script)

- **How to Run** (if applicable):
  1. Make the script executable:  
     ```bash
     chmod +x prep_data.sh
     ```  
  2. Run the script directly:  
     ```bash
     ./prep_data.sh
     ```  
  3. Or use the Makefile targets:  
     ```bash
     make prep    # Run the data preparation
     make clean   # Remove the data folder
     make all     # Clean + prepare
     make help    # Show available targets
